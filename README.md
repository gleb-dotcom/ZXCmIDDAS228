## 📌 О проекте

**zxcMIDDAS** — современный интернет-магазин альтернативной одежды и аксессуаров с бруталистским монохромным интерфейсом, аудио-эффектами дождя и полноценной системой управления.

### ✨ Основные возможности:
- 🛒 **Каталог товаров**: сортировка, поиск, фильтрация по категориям, карточки товаров с выбором размера.
- 🛍️ **Корзина и оформление заказов**: изоляция корзины под каждого пользователя, промокоды (`OPIUM` −15%, `VOID` −25%, `GRUNGE` −10%).
- 👤 **Личный кабинет**: профиль, аватар, история оформленных заказов.
- 🔐 **Система входа и ролей (RBAC)**:
  - Пароли защищены строгой политикой длины ($\ge 6$ символов).
  - Вход для администратора: логин `avice` / пароль `666666`.
- ⚙️ **Панель администратора**:
  - Добавление новых товаров (с готовыми пресетами или загрузкой фото).
  - Редактирование и удаление существующих позиций прямо из каталога.
  - Управление категориями.
- 🌧️ **Атмосфера**: встроенный генератор звука дождя и саб-дрона через Web Audio API, регулировка интенсивности дождя и эффекты молнии.
